## 二、阶段划分

### P0 · 技术地基核对（3 天）

依据：`[官方]` Google Search Essentials —— 技术要求 + 垃圾内容政策 + 关键最佳实践

- [ ] 逐条对照 Search Essentials 的技术要求清单（可抓取 / 可索引 / 返回正确状态码 / 移动可用）
- [ ] 用 GSC 的「网址检查」实测首页 + 3 个内容页
- [ ] robots.txt / sitemap / canonical 三件套确认无误
- [ ] Core Web Vitals 三指标是否在「良好」区间

**验收**：GSC 无技术类报错；CWV 报告无红色。

> 你站这部分基本已完成（239 页已收录，说明抓取和索引没问题）。**这一步主要是排除法**。

### P1 · 内容自检（1 周）

依据：`[官方]` Google 的「创建有帮助的内容」自查问题（People-first content self-assessment）

官方给了一组自问问题，直接拿来用，**不要用我编的阈值**：

1. 内容是否提供了原创信息、报道、研究或分析？
2. 内容是否提供了对该主题的实质性、完整性描述？
3. 内容是否提供了超越显而易见之处的见解或分析？
4. 如果内容借鉴了其他来源，是否提供了实质性的额外价值和原创性？
5. 标题/页面标题是否提供了内容的有用摘要，而不是耸动或标题党？
6. 你会把这个页面分享给朋友、推荐给需要的人吗？

**做法**：对 289 页做抽样（先抽 50 页），逐条打分为「是 / 否」。
「否」占多数的页面 → 补写或下线。

**验收**：抽样里「是」≥ 4 条的页面占比 > 60%。

> 这一步的产出不是「砍掉多少页」，而是**一份可复用的内容标准**：以后新写的页面先过这 6 问。

### P2 · 拿到排名资格（2–4 周，与 P1 并行）

依据：`[官方]` Google 明确「链接是排名信号之一」；`[官方]` 有专门的 link spam 政策

- [ ] 在掘金 / V2EX / linux.do 各发 1 篇有价值的内容，文末带原文链接
- [ ] 提交 10 个前端导航站
- [ ] 找回 3 篇被转载但未加链接的文章，请求补链

**不要做**：买链接、站群、群发模板邮件 —— 都在 `[官方]` spam policies 里明确列出。

**验收**：GSC → 链接，出现 ≥ 3 个新引荐域名。

### P3 · 长尾内容（4 周起）

依据：`[实践]` SERP 研究法 —— 写前先看前 10 名有没有答歪的

选题标准（三条同时满足）：

1. 是「报错 / 具体行为 / 版本差异」，不是概念词
2. 前 10 名里有 ≥ 2 篇没答清楚（`[判断]` 你自己翻一遍确认）
3. 你真的遇到过

**验收**：15 篇完成；4 周后至少 3 篇进入前 30。

### P4 · 百度（全程并行）

依据：`[官方]` 百度搜索资源平台文档

- [ ] 每天推 10 条（配额限 10/天，`[官方]` 限流规则）
- [ ] sitemap 配额放开后提交单文件（`[官方]` 不支持索引型 sitemap）
- [ ] 站点属性：类型改「自适应」、关联主体
- [ ] 每周看索引量

**验收**：索引量 > 0。

## 四、判断成败的唯一标准

`[判断]` 一个月后只看一件事：**GSC 里有没有出现平均排名 < 40 的词。**

- 有 → 方向对，继续加量
- 没有 → 问题在内容或外链，**不要加页面**

- ❌ 上线 1 个月内改 URL 结构 `[判断]`
- ❌ 用「搜不搜得到」判断成败 `[判断]`
