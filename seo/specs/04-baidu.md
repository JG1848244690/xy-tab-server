## 为什么是 0

推送 ≠ 收录。百度链路：

```
推送 → 待抓取队列 → 蜘蛛抓取 → 质量评估 → 进索引
 ↑已完成          ↑部分        ↑未开始      ↑未开始
```

新站有 **2–4 周考核期**，第二天就查到结果是不现实的。

## 已知的坑

**1. API 的 site 参数必须用裸域名**

```bash
# ❌ 返回 site init fail
site=https://code.kskbl.com.cn
# ✅
site=code.kskbl.com.cn
```

**2. sitemap 不要提交索引文件**

百度明确不支持 sitemap index，只提交 `/sitemap.xml` 单文件。

**3. 别挂 Cloudflare 橙云**

实测：橙云期间百度蜘蛛报「DNS 无法解析 IP」，切回灰云后 3 分钟恢复正常。

**4. 考核期内别改结构**

频繁改版会重置评估。只加内容，不动 URL。
