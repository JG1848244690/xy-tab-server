# Spec 03 · 长尾选题与写作规范

> 状态：待执行 · 优先级 P2（P0/P1 完成后开始）
> 核心：**长尾 ≠ 把大词加个后缀**，而是「几乎没人竞争的具体问题」

## 什么算合格的长尾

三条同时满足：

1. **排错 / 具体行为 / 版本差异** — 不是概念词
2. **SERP 前 10 名有 ≥ 2 篇没回答清楚** — 有缺口
3. **你自己真的遇到过** — 有一手材料

## 三类选题模板

### A. 报错类（竞争最低）

```
搜索形态：<完整报错信息>
例子：Module not found: Can't resolve 'fs'
     Hydration failed because the initial UI does not match
     Maximum update depth exceeded

页面结构：
  H1 报错原文
  一句话原因
  触发条件（3 种典型）
  解法（按场景分，不是按步骤）
  什么时候不该这么解
```

### B. 具体行为类

```
搜索形态：<某个 API 在某种情况下的行为>
例子：watch 里拿到旧值 / ref 在 setTimeout 里不更新
     useEffect 执行两次（React 18 StrictMode）

页面结构：
  H1 现象描述（用户的原话）
  结论先行
  为什么（机制）
  对比：常见误解 vs 真实行为
  代码验证（可直接跑）
```

### C. 版本差异类

```
搜索形态：<版本号 + 行为变化>
例子：Vue 3.4 defineModel 怎么用
     Vite 5 之后 build.target 默认值变了吗

页面结构：
  H1 版本 + 变化
  改动前后对比表
  迁移步骤
  兼容性注意
```

## 写作硬约束

| 项 | 要求 |
| --- | --- |
| 字数 | ≥ 1500，不设上限 |
| 代码 | 必须能跑（自己跑过） |
| 一手材料 | 至少一处「只有实际用过才知道」的细节 |
| 标题 | 用用户会搜的说法，不用题目口吻 |
| 发布时间 | 发布后 7 天内推给百度 + 加内链 |

## 标题改写对照

```
❌ 你是如何封装一个组件的？
✅ React 组件封装的 5 种模式与取舍

❌ 什么是 reflow
✅ reflow 与 repaint 的区别，以及哪些 CSS 属性会触发

❌ 算法：数组原型对象的最后一个元素
✅ 取数组最后一个元素的 5 种写法与性能对比

❌ vuex 的流程
✅ Vuex 一次 dispatch 到 mutation 的完整流程（含源码位置）
```

## 验收

- [ ] 15 篇完成，全部 ≥ 1500 字
- [ ] 每篇至少 1 个可运行代码块
- [ ] 5 篇在发布 4 周内进入前 20
- [ ] 至少 1 篇的排名**不依赖外链**（纯内容赢的）

最后一条是关键：**它证明你的内容策略成立**，可以复制。
