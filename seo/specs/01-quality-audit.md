# Spec 01 · 内容质量体检

> 状态：待执行 · 优先级 P0 · 预计 4 小时
> 依据：`[官方]` Google「创建有帮助的内容」自查问题
> https://developers.google.com/search/docs/fundamentals/creating-helpful-content

## 为什么

289 道题里有相当一部分来自语雀导入（早期还删过一批 OCR 垃圾题）。
这类页面的典型特征：正文短、没代码、没对比、表述是「题目口吻」。

Google 没有公布任何「薄页比例」的阈值，所以**不要用百分比判断**，
改用官方给的 6 个自查问题逐页打分。

## 六个自查问题（官方原文，不要改写）

1. 内容是否提供了原创信息、报道、研究或分析？
2. 内容是否提供了对该主题的实质性、完整性描述？
3. 内容是否提供了超越显而易见之处的见解或分析？
4. 如果内容借鉴了其他来源，是否提供了实质性的额外价值和原创性？
5. 标题是否提供了内容的有用摘要，而不是耸动或标题党？
6. 你会把这个页面分享给朋友、推荐给需要的人吗？

## 执行方式

**第一步：抽样 50 页**（随机，覆盖六个题库）

每页对 6 个问题打「是 / 否」，记录到 CSV。

**第二步：分类**

| 命中「是」的数量 | 处理 |
| --- | --- |
| ≥ 4 | 保留 |
| 2–3 | 补写（扩到 2500 字，补代码/对比/边界） |
| ≤ 1 | 下线（410）或合并 |

**第三步：全量执行**

按抽样结果校准标准后，再把剩余 239 页过一遍。

## 产出

`seo/audits/2026-11-quality-audit.csv`

```
url, title, q1,q2,q3,q4,q5,q6, score, verdict(keep/expand/merge/drop)
```

## 验收

- [ ] 50 页抽样完成，打分记录在案
- [ ] 全量 289 页完成分类
- [ ] 「保留」占比 > 60%
- [ ] 补写名单里前 5 篇已扩写完成
- [ ] 下线页面的 URL 返回 410（不是 200 空页）

## 风险

- **别一次下线太多**：分两周做，单日不超过 50 页
- **别为凑字数灌水**：删掉读者不会少知道任何事的话，比加十段废话强
- **保留原始判断记录**：三个月后你会想知道当初为什么砍这些页
