# 指标定义与取数口径

> 只记这 6 个。多一个都不要，否则每周都在做报表而不是做事。

## 1. 有效索引率

```
有效索引率 = 已收录页面数 ÷ 想收录的页面数
```

- **在哪看**：GSC → 网页 → 已编入索引
- **口径**：想收录 = sitemap 里的 URL 数（当前 408）
- **基线**：239 / 408 ≈ 59%
- **及格线**：> 70%；> 85% 才进入「成长期」

## 2. 平均排名（核心指标）

- **在哪看**：GSC → 效果 → 平均排名
- **怎么看**：不看绝对值，看**趋势**。90 → 60 是进步，60 → 50 是微调。
- **及格线**：出现第一个 < 40 的词 = 站点开始有排名能力

## 3. 非品牌点击

```
非品牌点击 = 总点击 − 品牌词点击
```

- **为什么**：品牌词点击只说明老用户记得你，不说明获取能力
- **在哪看**：GSC → 效果 → 查询 → 排除含「序言」的词
- **基线**：0

## 4. 引荐域名（RD）

- **在哪看**：第三方外链工具，或 GSC → 链接
- **标准**：不同站的链接才算一个；100 条来自同一站 ≈ 1 个
- **目标**：P1 结束后 ≥ 3

## 5. CTR（只在排名前 10 时看）

```
CTR = 点击 ÷ 曝光
```

- 排名 30 名以外时 CTR 无意义，别优化
- 前 10 名 CTR < 2% → 改标题

## 6. 百度索引量

- **在哪看**：百度站长 → 数据统计 → 索引量
- **基线**：0
- **意义**：这是中文站的主战场，Google 只是补充

## 每周一取数（10 分钟）

```
GSC    收录数 / 平均排名 / 非品牌点击
百度   索引量 / 抓取频次
外链   新增引荐域名
```

把三个数字填进 `roadmap.md` 的「进展记录」，一行就够。

## 反模式

- ❌ 每天看 `site:` 结果（会焦虑，且没有信息量）
- ❌ 用「搜不搜得到」判断成败（新站必然搜不到）
- ❌ 只看流量不看排名趋势（流量受季节、事件影响大）
