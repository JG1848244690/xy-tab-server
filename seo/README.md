# seo/

序言（code.kskbl.com.cn / hls.kskbl.com.cn）的 SEO 工作区。

这里放三类东西：**计划**（roadmap）、**规格**（specs）、**记录**（audits）。
不放代码，代码在 `apps/`。

## 目录

```
seo/
├── README.md               ← 你在这里
├── roadmap.md              ← 总体路线图（12 个月）
├── metrics.md              ← 指标定义与取数口径
└── specs/
    ├── 01-quality-audit.md    ← 289 页体检（当前最优先）
    ├── 02-backlinks.md        ← 外链获取
    ├── 03-long-tail.md        ← 长尾选题与写作规范
    └── 04-baidu.md            ← 百度收录推进
```

## 怎么用

- **每周一**：看 `roadmap.md` 的本周任务，做完打勾
- **每月第一周**：按 `metrics.md` 取数，把数字填进 roadmap 的「进展」
- **新想法**：先写成 `specs/` 下的一篇，写清楚「做什么、为什么、怎么验收」，再动手

一份 spec 不合格的标志：**读完不知道怎么做完、也不知道怎么判断做完了。**

## 硬约束（别和它们较劲）

1. 域名不足 2 个月，Google 的信任积累需要 3–6 个月
2. 阿里云北京 → Google API 不通（所以不做服务端 GA 拉数）
3. 百度对新站有 2–4 周考核期
4. 单人维护，每周可用时间按 **6 小时** 估算
