# 系统监控采集

确认主机上的 API 容器名、上传路径、备份目录和日志路径与 `collect-host.py` 中的配置相符。由运维先在宿主机执行采集脚本并核对 `/var/lib/hls-monitor/snapshot.json`，再纳入现有发布流程。采集任务可以每 5 分钟运行一次。脚本只发布固定指标，应用容器通过 Compose 的监控覆盖文件只读挂载快照目录。现有部署需要显式启用覆盖文件，并保持后续发布使用同一组 Compose 文件。

快照超过 12 分钟会标记为过期。站外探测可使用已有 `/api-hls/health`，通知目的地由运维配置。备份状态来自现有备份日志的成功和演练标记，代表主机已经记录的执行结果。
