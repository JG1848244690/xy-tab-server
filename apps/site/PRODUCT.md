# PRODUCT.md — HLS 面试题库(apps/site)

## 产品
面向求职工程师的**免费面试题库公开站**。内容:前端/算法面试题(分层解析 + 记忆口诀)、
专题题库、每周荐文荟萃。内容生产在后台 SPA,质量控制走 AI+人工双审,
本站是纯静态(Next.js SSG)的只读门面。

## 用户与首要任务
- 用户:准备前端/算法面试的工程师(中文)。
- 首要任务:**快速读题、读懂分层答案、按专题/标签系统性复习**。
- 成功 = 5 秒内定位到想看的题;答案区读起来舒服;代码块清晰;手机上能刷。

## 模式
**Read**(阅读理解型表面)+ 工具属性辅佐。结构服务于理解,克制与精确优于表达。

## 已确认的设计决策(2026-10-18,用户拍板)
- 视觉方向:**工程阅读型**(MDN/LeetCode 一路:克制的工程风、代码块是视觉主角、
  信息密度优先)——不要编辑杂志风。
- 必须支持:暗色模式、移动端。
- 反对:纯 AI 默认脸(紫色渐变/奶油底/卡片橱窗/无个性布局)。
- 内容宽度过窄是用户明确痛点 —— 版心放宽,阅读列与页面布局分离。

## 边界
- 静态导出(output: export),无运行时个性化(收藏/登录在 backlog:S5)。
- 构建期从 /public/* API 拉数据,页面数随题库增长。
