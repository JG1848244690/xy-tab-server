# 前台视觉改版:四个方向(2026-10-30)

## 先说现在为什么"平"

1. **没有主色,只有状态色**。页面 95% 是 `#f6f7f9 / #fff / #0f1a24`,蓝色只出现在按钮和链接上,像"默认组件库"。
2. **导航里的「贡献题目」是实心蓝胶囊**。它和正文抢焦点,又没有任何视觉体系支撑,所以显得突兀、丑。
3. **所有卡片长得一样**:同样的圆角、同样的 1px 边框、同样的阴影。题库、今日一题、复习节奏没有层级差别。
4. **字号跨度太小**:正文 13–16px,标题 16–26px,缺少 40px+ 的展示级排版,页面没有"第一眼"。
5. **中文没有字体性格**。系统黑体 + 系统灰,读起来舒服,但不像一个有主张的产品。
6. **动效是"通用入场"**。淡入上浮 + 卡片 hover,任何模板站都能加,不构成记忆点。

改版共通的三条硬规则:

- **导航不再放实心按钮**,「贡献题目」改成文字 + 细节(下划线/印章/箭头),全站只保留一个主 CTA。
- **建立一套真的色彩系统**:底色、墨色、一个主强调色、四个分类色;颜色只用来编码信息,不做装饰。
- **拉开字号层级**:至少一个 40–56px 的展示级标题,正文 15–16px,元信息 12–13px。

## 方向 A:「序言 · 书页」Editorial(推荐)

把题库当成一本可以翻的书:序言、目录、页边注、页码、印章。品牌名"序言"本身就是这个隐喻。

**参考**
- [Books of Design(Awwwards SOTD)](https://www.awwwards.com/sites/books-of-design)
- [Mosby's Files(Typography Honors)](https://www.awwwards.com/sites/mosbys-files)
- [Seasoned / Koto(SOTD)](https://www.awwwards.com/sites/seasoned)
- [A24 / Ravi Klaassens(SOTD 2026-10-26)](https://www.awwwards.com/sites/a24)

**色彩**
| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 纸 | `#F3F2EC` | 页面底色(冷一点的纸,不是网红米色) |
| 墨 | `#141310` | 标题/正文 |
| 次墨 | `#6E6A60` | 摘要/元信息 |
| 朱砂 | `#B5342A` | 印章、进度、唯一强调 |
| 靛青 | `#24406B` | 链接/选中 |
| 分类色 | `#315C9B` `#2F6B57` `#A15C2F` `#6B4E8E` | 四个题库的页签/小色块 |

**字体**
- 展示:思源宋体 / Noto Serif SC(600–700),中文标题用衬线,立刻和 90% 的开发者站点区分开。
- 正文:思源黑体 / PingFang SC。
- 数据:等宽只用于题号、计数,不再给每个标签都套 mono。

**版式**
- 首页像"扉页 + 目录":左侧一条窄页边注(题数、更新时间),右侧大标题 + 一段导语。
- 题库列表改成**目录**:标题 …………… 题数,点线引导,悬停时整行淡入分类色。
- 「今日一题」是一张**摘录卡**:细边框、无圆角或 2px 小圆角、右上角页码,不像 SaaS 卡片。
- 题目页:正文 65–72ch,右侧页边注放方向/技术栈/知识点,像批注而不是表单。

**导航**
- 纯文字 + 细下划线;「贡献题目」是文字 + 朱砂小方印,悬停时印章"盖下"(缩放 + 墨色扩散)。没有蓝色胶囊。

**动效**
- 页面切换像翻页:极轻的纵向位移(已有)。
- 阅读进度:顶部 1px 朱砂线,像书签。
- 悬停:目录行点线延伸、印章按压、链接墨迹下划线。
- 不做滚动视差、不做卡片集体上浮。

**气质**:安静、贵、适合长文阅读;靠字体和留白撑高级感。
**风险**:宋体需要自托管字体子集(约 200–400KB);没有大图/插画,首页要靠排版取胜。

```
┌──────────────────────────────────────────────┐
│ 序言        题库  标签  文章  荟萃      贡献题目 ▪│
├──────────┬───────────────────────────────────┤
│ 297 题    │  面试题,                             │
│ 4 个题库  │  按原理分层讲透                       │
│ 10.30    │  每道题都有分层答案、结论与口诀。        │
│          │                                     │
│          │  ┌ 今日一题 ────────────── p.017 ┐   │
│          │  │ 闭包是什么?如何实现?           │   │
│          │  └──────────────────────────────┘   │
├──────────┴───────────────────────────────────┤
│ 目录                                          │
│ 工程与网络 …………………………………………………………… 7        │
│ 算法与数据结构 ………………………………………………… 24       │
│ 框架与生态 ………………………………………………………… 92       │

```

**工作量**:设计 token + 首页 1.5 天;列表/题库/标签模板 1 天;题目页 1 天;字体与细节 0.5 天。

## 方向 B:「蓝图 · 剖面」Blueprint

把每道题当成系统的一张工程图纸:网格、尺寸标注、剖面线、图签。

**参考**
- [Fiddle.Digital — Blueprints(Awwwards)](https://www.awwwards.com/inspiration/blueprints-fiddle-digital-design-agency)
- [Heron AI(SOTD 2026-10-09,建筑蓝图风格)](https://www.awwwards.com/sites/heron-ai)
- [Thenest — Scroll-Drawn Section Line A—A](https://www.awwwards.com/inspiration/main-benefits-thenest)
- [SUTÉRA — Blueprint Reality](https://www.awwwards.com/sites/sutera)

**色彩**
| 角色 | 色值 |
| --- | --- |
| 图纸白 | `#EDF2F7` |
| 墨蓝 | `#0E2A47` |
| 线蓝 | `#2E6DA4` |
| 安全橙 | `#E4572E` |
| 标注灰 | `#7C8FA6` |

**字体**:无衬线粗体 + 等宽标注(尺寸、编号、坐标)。
**版式**:24px 网格纸底纹;元素带角标、尺寸线;标题配 `DWG-01` 图签;卡片像图纸窗口,不是圆角卡。
**导航**:顶部做成图签条,CTA 是描边图章。
**动效**:SVG 线条描绘、十字光标坐标、hover 出现尺寸标注。

**气质**:硬核、工程感、和"按原理分层"最贴。
**风险**:容易做成"蓝图模板";长文阅读会被网格干扰,题目页需要大幅降噪。

## 方向 C:「夜航 · 终端」Dark Terminal

面向开发者的深色工作台,带一点实验室的冷感。

**参考**
- [I'm not a bot(Sang Young Bae)](https://www.awwwards.com/sites/im-not-a-bot)
- [Igloo Inc(Developer SOTY 2024)](https://www.awwwards.com/sites/igloo-inc)
- [Bruno Simon Portfolio](https://www.awwwards.com/sites/bruno-simon-portfolio)

**色彩**:`#0A0C10` 底、`#EDEAE3` 字、`#FFB224` 琥珀强调、`#7C8FA6` 次字。
**字体**:等宽标题 + 无衬线正文(标题不做全站 mono,只在数字/命令)。
**版式**:命令面板式 hero(`find /questions -tag closure`),列表像终端输出,卡片是 1px 描边窗格。
**导航**:裸文字 + 光标;贡献入口写成命令。
**动效**:打字机(只一次)、光标闪烁、`⌘K` 搜索面板。
**气质**:开发者一眼懂,记忆点强。
**风险**:深色长文阅读累;容易落入"黑底 + 荧光色"的俗套;用户已说"现在只是黑白",这个方向本质上还是黑白。

## 方向 D(备选):「色谱 · 海报」Swiss Color

如果就是想要"眼前一亮",用大色块和海报级排版,不靠字体。

**参考**:[A24](https://www.awwwards.com/sites/a24)、[Palace Skateboards](https://www.awwwards.com/sites/palace-skateboards)、[Awards Racing(SOTD 2026-10-27)](https://www.awwwards.com/sites/awards-racing)
**色彩**:纸 `#F5F1E8`、墨 `#151515`、四块高饱和分类色 `#2F5BFF` `#FF5A36` `#0E9F6E` `#F5C518`。
**版式**:非对称大网格,首页每个题库是一块色板 + 超大编号;标题 64–96px。
**风险**:饱和度高,容易"潮但吵";长文页要克制;高级感取决于执行精度。

## 选型建议

| 方向 | 眼前一亮 | 高级/优雅 | 长文阅读 | 与"序言"契合 | 开发量 |
| --- | --- | --- | --- | --- | --- |
| A 书页 | 中高 | **高** | **最好** | **最高** | 中 |
| B 蓝图 | **高** | 中高 | 中 | 高 | 中高 |
| C 终端 | 中 | 中 | 差 | 中 | 低 |
| D 色谱 | **最高** | 中 | 中 | 中 | 中 |

**推荐 A,并吸收 B 的一点点"技术注记"**:书页的排版 + 页边注里用等宽写方向/技术栈/题号。这样既有中文产品的辨识度,也不会变成纯文艺。
如果更想要"第一眼炸",选 D;如果更想要"工程师硬核",选 B。

## 下一步

选定后我按这个顺序落地:
1. 设计 token(色/字/间距/圆角/阴影)+ 导航重构(去掉蓝色胶囊)
2. 首页(扉页 + 目录 + 今日一题)
3. 列表/题库/标签模板
4. 题目阅读页(页边注 + 朱砂进度线)
5. 动效与可访问性、Core Web Vitals 回归
