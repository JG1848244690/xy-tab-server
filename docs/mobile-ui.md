# 移动端 UI(2026-11-14)

## 为什么不再用「请用电脑打开」

原来是 `/test-center/practice/:id` 外面包一层 `MobileGate`,手机上直接显示提示。问题是:
刷题恰恰是手机上最自然的使用场景(通勤、睡前),把人挡在门外等于这个功能只服务电脑。

现在改成**两套 UI 共用同一套 API**:

| | 桌面端 | 移动端 |
| --- | --- | --- |
| 入口 | `/home`、`/test-center` | `/m/questions` |
| 布局 | 侧栏 + 多栏工作台 | 单列 + 底部 tab |
| 能做什么 | 全部(出题/审核/文章/绘图) | 看题、刷题、账号 |
| 编辑器 | Monaco / 富文本 | 纯 textarea(自动用等宽字体) |

`MobileGate` 只保留在 X6 绘图页——那个页面在手机上确实没法用。

## 路由

| 路由 | 说明 |
| --- | --- |
| `/m` | 重定向到 `/m/questions` |
| `/m/questions` | 题库列表:搜索 + 全部/未完成/已完成 + 加载更多 |
| `/m/practice/:id` | 刷题:题目、作答、自评、参考答案折叠 |
| `/m/me` | 账号、明暗、联系作者、退出、切桌面版 |

## 跳转规则

- `/` 和登录成功后:移动端 → `/m/questions`,桌面 → `/home`
- 手机误入 `/home`、`/test-center`、`/test-center/practice/:id` → 自动转 `/m/questions`
- `/m/me` 里的「切换到桌面版」→ `/home`(手机上依然能用,只是排版按桌面)

## 刷题的交互

桌面端是「左题目 / 右编辑器」双栏,手机放不下,改成单列:

```
标题 / 难度 / 计时
题目内容(Markdown)
我的作答(textarea)
[没答上来] [答对了]        ← 自评,和服务端 markCorrect 同一套接口
参考答案(折叠)
```

提交顺序与桌面一致:`POST /questions/:id/submit` → `PATCH /questions/:id/attempts/:attemptId`,
统计和「已完成」状态由后端算,移动端不重复实现。
